# ROMSneeze

A stupidly simple catalog of good ROM hacks.

The goal is basically: find a hack, check the difficulty, click the project/patch page, and go play it.

## Difficulty

- **Beginner** — first Kaizo / approachable hacks
- **Easy** — low-end Kaizo and early precision
- **Medium** — intermediate to advanced
- **Hard** — expert-level stuff
- **Expert** — extremely demanding
- **Impossible** — borderline ridiculous

## What's here

ROMSneeze focuses on ROM hacks, especially Kaizo, across different games and systems. The site does **not** distribute copyrighted ROM images. Entries should point toward legitimate patch files, author pages, project pages, or established ROM-hacking resources.

## Contributing

Add good hacks. Keep the difficulty labels useful. Link to the actual project/patch page when possible. Don't upload copyrighted base ROMs.
