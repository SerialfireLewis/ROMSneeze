# Patches

ROMSneeze uses patch files instead of ROM images. Modern SMW Central releases are generally distributed as **BPS** inside their download archives; older hacks may use **IPS**. The links below point to the hack's official/established project page where the current patch can be downloaded.

## Patching

Use Floating IPS (FLIPS) for IPS/BPS patches. You need your own clean, legally obtained base ROM. Do not upload base ROMs here.
